# Marketplace notes: SaaS Admin Dashboard

This is a generic web-app source starter. **It is not a GitHub Marketplace Action or GitHub App yet.**

GitHub Marketplace is for GitHub Apps and GitHub Actions. To list this project there, first build a GitHub-native integration that solves a GitHub workflow problem (for example, an Action that validates/builds/deploys this project). For a paid GitHub App, publisher verification and Marketplace billing integration are required.

Suggested listing angle: use this starter as the dashboard/product UI for a related GitHub integration.
