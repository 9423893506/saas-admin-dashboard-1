# SaaS Admin Dashboard

A responsive admin dashboard starter with KPI cards, charts, user table, and dark theme.

## Run
Open `index.html` in a browser. No build step required.

## Status
This is a functional front-end starter/demo, not a production SaaS. Add authentication, server-side persistence, security review, tests, and deployment infrastructure before selling as a production product.
